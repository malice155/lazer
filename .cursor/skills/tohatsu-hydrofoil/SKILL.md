# Промт: гидрокрыло Tohatsu 9.8

Спроектировать **листовое** гидрокрыло на антикавитационную плиту. Цель — быстрее глисс на ПВХ 3.2–3.6 м, не «формула-1».

Мотор по умолчанию: **2-такт Tohatsu M9.8B** (26 кг, винт 8.5×9). Тот же низ у Nissan NS9.8 и многих клонов. **4-такт MFS9.8 — другой редуктор**, те же константы не копировать без замера.

## Жёсткие правила

- Не сверлить редуктор и АКП, пока пользователь явно не попросит. Крепление: U-вырез + зажимные планки, M6, пазы.
- Задняя кромка крыла **впереди плоскости винта**.
- Гибы законцовок вниз: **15°**, Rвн **3 мм**, оси на **±108 мм**. STEP — после гиба, DXF — развёртка (слой BEND не резать). Ручей V24, не пуансон R47.
- Толщина листа ≤ 3 мм (АМГ) / 2 мм (нерж). Толще на 9.8 — лишнее сопротивление (практика DIY ≤10 л.с.).
- Официального CAD АКП нет. `LEG_NOTCH_W`, `AV_PLATE_W`, `AV_PLATE_THICK` — **MEASURE**.
- Код: `cad/parts/tohatsu_m98_hydrofoil.py`. Сборка: `cad/.venv/bin/python cad/build.py tohatsu-m98-hydrofoil`

## Опора из открытых данных (не заводской чертёж)

| Источник | Что взяли |
|---|---|
| Tohatsu M9.8B spec | 7.2 кВт, 26 кг, 8.5×9, АКП 30–50 мм ниже днища |
| Серийные съёмные 5–9.8 л.с. (РФ, без сверления) | конверт **290×320 мм** |
| SE Sport 200 (8–40 hp) | 343×363 мм, сверловка; на 9.8 ставят часто, для 9.8 крупновато |

## Что снять штангенциркулем

1. Ширина ноги у АКП → `LEG_NOTCH_W` = замер + 6…8 мм  
2. Ширина АКП → `AV_PLATE_W`  
3. Толщина АКП → `AV_PLATE_THICK`  
4. Длина АКП и зазор до диска винта (кромка крыла не в винт)

Пока нет замеров — оставляй дефолты и пиши это вслух.
