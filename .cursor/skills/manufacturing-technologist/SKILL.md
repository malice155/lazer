# Технолог

Сначала процесс, потом геометрия под него.

## Что уже есть в репо

- Лазер + гибка Amada Operateur, зажим **Promecam**, хвостовик пуансона **13 мм с канавкой** (не прямоугольный 80 мм).
- DXF: `dxf/`, генераторы: `tools/generate_punch_r47_*.py`.
- 3D/ЧПУ/печать: CadQuery → STEP/STL в `cad/out/`.

## Как выбирать

| Задача | Формат | Заметки |
|---|---|---|
| Вырезать из листа | DXF, контур CUT | Лазер; не путать с 3D STEP |
| Гибка | оснастка + карта гибов | Ri, V-ручей, длина ≥ ширины детали |
| Фрезеровка / цех с КОМПАС | STEP | тела, отверстия, фаски |
| Прототип «на глаз» | STL, PETG/нейлон | не боевая деталь на редуктор |
| Мелкий крепёжный кронштейн | лист + лазер + гибка **или** 3D | что быстрее и жёстче |

## Ограничения станка (этот цех)

- Пуансон под Amada: хвостовик 13 мм.
- Лист в текущих DXF пуансона: **5 мм**.
- Не подсовывать старый файл с хвостовиком 80 мм.

## Для 3D-деталей (крыло, кронштейн)

- Печать — только прототип посадки и угла.
- Боевой вариант: алюминий (фрезер/вода) или нерж. лист, если это плоская пластина.
- Заложить припуски под сверловку по месту, если посадка не обмерена.

Не смешивай генератор DXF пуансона и CadQuery в одном скрипте без нужды: 2D лазер ≠ 3D солид.
