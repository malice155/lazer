# Ninja AF400EU — кулинарная книга Натальи

Приложение для iPhone по аэрогрилю **Ninja Foodi MAX Dual Zone AF400EU**: вся инструкция,
официальные таблицы приготовления и рецепты — на русском языке.

## Что внутри

- **Как пользоваться** — перевод инструкции: все шесть режимов с температурами и шагами таймера,
  SYNC, MATCH, готовка в одной зоне, решётка-подставка, чистка, вопросы и неполадки, безопасность.
- **Таблицы приготовления** — официальные значения Ninja для этой модели: Air Fry, Max Crisp,
  Roast, Dehydrate и готовые пары для SYNC. Работает поиск по продукту.
- **Рецепты** — по категориям: курица, мясо, рыба, овощи, закуски, десерты, основы. У каждого
  рецепта указаны режим, температура, время и нужна ли решётка — отдельно для Зоны 1 и Зоны 2.
- **Избранное, оценки и заметки** — сердечко, звёзды, свободный комментарий и счётчик «готовила N раз».
- **Таймеры двух зон** — с напоминанием встряхнуть корзину, звуком и вибрацией.
- **Экспорт и импорт заметок** в файл — на случай смены телефона.

Всё работает офлайн: после первого открытия интернет больше не нужен.

## Установка на iPhone

1. Открыть адрес приложения в **Safari** (именно в Safari, не в Chrome).
2. Нажать кнопку «Поделиться» — квадрат со стрелкой вверх внизу экрана.
3. Выбрать **«На экран „Домой“»** и нажать «Добавить».
4. Приложение появится на рабочем столе обычной иконкой и будет открываться на весь экран.

## Публикация

Приложение собирается и выкладывается на GitHub Pages автоматически при изменениях в папке
`ninja-af400eu/`. Один раз нужно включить Pages в настройках репозитория:
**Settings → Pages → Source: GitHub Actions**.

После этого адрес приложения: `https://malice155.github.io/lazer/`

Важно: на бесплатном тарифе GitHub Pages работает только в публичных репозиториях. Если репозиторий
приватный, нужно либо сделать его публичным (Settings → General → Change visibility), либо GitHub Pro.

## Один файл без интернета и без хостинга

`Наталья-Ninja-AF400EU.html` — всё приложение целиком в одном файле: скачал, открыл в браузере,
работает. Хостинг и сборка не нужны. Пересобрать после правок:

```bash
npm run build:single   # результат: dist-single/index.html
```

## Разработка

```bash
cd ninja-af400eu
npm install
npm run dev      # локальный сервер
npm run build    # проверка типов и продакшн-сборка
npm run preview  # посмотреть собранную версию
```

Иконки перегенерируются скриптом (нужен Pillow):

```bash
python3 tools/make_icons.py
```

## Откуда взят контент

Всё переведено с официальных материалов SharkNinja:

- руководство по эксплуатации AF400EU;
- книга рецептов и таблицы приготовления AF400EU из комплекта поставки;
- книга рецептов Ninja для двухзонных аэрогрилей (те же режимы и та же логика зон).

У каждого рецепта в приложении подписан источник.
