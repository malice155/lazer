# Гидрокрыло Tohatsu 9.8 (M9.8B)

Параметрика: `cad/parts/tohatsu_m98_hydrofoil.py`  
Выдача: `cad/out/tohatsu-m98-hydrofoil.step` (КОМПАС), `.dxf` (лазер), `.stl` (прототип).  
Зажимы: `tohatsu-m98-clamp` — **2 шт**, вторую зеркалить по Y.

Это **не заводской чертёж**. Конверт 290×320 мм взят с серийных съёмных крыльев 5–9.8 л.с. Вырез и ширина АКП — оценка по фото/винту 8.5″; перед резкой металла замерить мотор.

## Сборка

```bash
cad/.venv/bin/python cad/build.py tohatsu-m98-hydrofoil
cad/.venv/bin/python cad/build.py tohatsu-m98-clamp
```

## Замеры (обязательно до «боевого» листа)

| Параметр | Дефолт, мм | Где мерить |
|---|---|---|
| `LEG_NOTCH_W` | 88 | ширина ноги у АКП + 6…8 |
| `LEG_NOTCH_DEPTH` | 118 | от передней кромки плиты до корпуса |
| `AV_PLATE_W` | 158 | ширина антикавитационной плиты |
| `AV_PLATE_THICK` | 6 | толщина АКП |

4-такт **MFS9.8** — другая нога, дефолты не переносить.

## Гибы

Два гиба, законцовки **вниз**. STEP — уже согнутая деталь. DXF — плоская развёртка: слой `CUT` резать, слой `BEND` не резать.

| | |
|---|---|
| Угол | **15°** вниз, обе стороны |
| Внутренний радиус | **3 мм** (= толщина листа) |
| Ось от центра | **±108 мм** |
| Полка у носа | 32 мм |
| Полка у задней кромки | 52 мм |
| До паза M6 | 11 мм |
| Ручей | **V24** (для 3 мм можно V20). Пуансон R47 для этого гиба не нужен |

## Как делать в этом цехе

1. Лазер, слой `CUT`: крыло + 2 зажима, лист **АМГ-5м 3 мм** (или нерж 2 мм).
2. Листогиб: две линии `BEND`, 15° вниз, Rвн 3, ручей V24.
3. Кромки скруглить напильником. Острый нос не нужен.
4. Крепёж: M6×25 A4, гайка с нейлоном, шайбы, 4 резиновые прокладки. Зажим **без сверления** АКП: болты снаружи плиты, планки снизу.
5. Посадка: картонный шаблон из DXF, потом металл. Задняя кромка не в винт.
