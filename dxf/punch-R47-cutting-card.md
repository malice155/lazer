# Лазер: пластины пуансона R47

## Файлы
- `punch-R47-plate-5mm.dxf` — 1 контур (для ЧПУ / ручного размножения)
- `punch-R47-nest-32pcs-5mm.dxf` — готовый нестинг **32 шт** (~664×492 мм)
- `punch-R47-gauge-5mm.dxf` — шаблоны контроля радиуса R47 (внутр. + наруж.), 2 шт
- `punch-R47-preview.png` — эскиз профиля

## Параметры пластины пуансона
| | |
|---|---|
| Материал | лист **5 мм** (Ст3 / S235 и аналог) |
| Количество | **32 шт** |
| Длина пакета после сборки | **160 мм** (деталь 130 мм) |
| Радиус носика | **R47** |
| Угол пуансона | **90°** |
| Ширина хвостовика | **80 мм** |
| Высота пластины | **120 мм** |
| Отверстия сборки | **4×Ø10** (шпильки M10) |

## Слои DXF
- `CUT` (красный) — рез
- `ENGRAVE` (зелёный) — маркировка (по желанию)
- `INFO` — не резать

## Сборка
1. Вырезать 32 пластин (+ 2 калибра из `punch-R47-gauge-5mm.dxf`).
2. Собрать пакет на 4 шпильки M10, выровнять по контуру.
3. Обварить по периметру короткими швами вразброс (чтобы не повело).
4. Зачистить носик; проверить калибром R47.
5. Сверху хвостовика 80 мм приварить/прикрутить переходник под зажим вашего листогиба.

## Лазер
- Ед. измерения DXF: **мм**
- Контур в номинале. Компенсацию керифа задайте в ПО станка так, чтобы **R47 ≥ чертежа** (лучше чуть больше, чем меньше).
- Рекомендуемый зазор нестинга: уже заложен **3 мм**.
